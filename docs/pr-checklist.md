## Pull Request Checklist 

- The PR links to the Jira story and explains what changed
- The acceptance criteria have been tested, and the PR describes how
- Each new story includes at least one automated test
- The required lint-and-test check is green
- The AI log documents any AI-assisted work
- Documentation is up to date. If an API contract changed, the shared wiki is updated
- At least one teammate has approved the PR before merging into main

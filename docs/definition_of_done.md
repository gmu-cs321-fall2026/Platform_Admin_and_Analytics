# Definition of Done 

- All code is completed and committed to GitHub
- Before merging, at least one other member approves the code 
- Tests have been made for the main functionality of the code and all pass
- Every criteria and requirement has been tested and validated
- All complete code has been merged to the main branch and works 
- Any AI-assisted code has been included in commit or ai-log
- All major bugs are fixed and all team members agree on the final product
- API’s and integration with other subsystems are tested and working
- Documentation is complete and up to date 
- Dashboards display all required information accurately and is readable
- Lint-and-Test check is green before merging into main
